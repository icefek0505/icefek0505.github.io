MyFinance — политика конфиденциальности

MyFinance — личное приложение для учёта собственных финансов. Им пользуется только его владелец; оно не предоставляется другим людям.

Какие данные обрабатываются

Остатки и операции по счетам владельца, полученные с его согласия через Enable Banking (только чтение), выписки, которые он сам загружает, и заметки, которые он сам вводит.

Где хранятся данные

Только на телефоне владельца. У приложения нет собственного сервера; данные никуда не копируются и не продаются.

Кому передаются данные

  • Enable Banking — чтобы получить операции и остатки из банков по согласию владельца.
  • Выбранный ИИ-сервис (Anthropic Claude или Google Gemini) — только те сведения, которые нужны для ответа в чате и для разметки операций по категориям.

Как отозвать доступ

Доступ к банку можно отозвать в любой момент в интернет-банке или в Enable Banking; он также истекает сам (обычно через 180 дней). Удаление приложения удаляет все данные с телефона.

English summary

MyFinance is a personal, single-user finance app. Account data obtained through Enable Banking (read-only, with the owner's consent) is stored only on the owner's phone and is shared only with Enable Banking and the AI service the owner chooses (Anthropic Claude or Google Gemini) to answer the owner's own questions. There is no server and no data is sold or shared with anyone else.
